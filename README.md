# Settl Web

Frontend application built with Next.js.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Tech Stack

- **Framework:** Next.js v16.2.9
- **Language:** TypeScript
- **Styling:** CSS

## Project Structure

- `src/app/` - Next.js App Router pages and components
- `public/` - Static assets
